# 3DS SaveBridge Multi

自作の3DS CIA側とAndroid APK側で、Azaharの複数ゲームのセーブを同期する試作版です。

## できること

- AndroidでAzaharのユーザーフォルダを一度選択すると、`title/00040000/.../data/00000001` を自動検索
- 3DS CIAが公開するゲーム一覧と照合し、複数ゲームをチェックして同期
- 15秒ごとに差分をハッシュ比較し、新しい側を反映
- 同時変更は競合として停止し、上書き前のバックアップとロールバック用ジャーナルを作成
- パス検証、サイズ上限（16 MiB）、SHA-256検証、復旧処理を実装

## 重要な制約

3DSのゲーム実行中にセーブを読み書きすると破損するため、同期前にゲームを終了してください。CIAは3DS上で起動したままにする必要があります。Androidの同期はアプリが前面にあり「同期中」の間に実行されます。OSに強制終了された状態からの完全なバックグラウンド自動起動や、ゲーム終了イベントの検出は3DS/Androidの権限制約上この版では行いません。

初回はAndroidのローカル保存と3DS保存が両方存在する場合、勝手に上書きせず競合選択を表示します。

## ビルド成果物

- `SaveBridge-v0.3.apk` — Android 8.0以降向け、デバッグ署名
- `ctr/SaveBridgeMulti.3dsx` / `ctr/SaveBridgeMulti.elf` — CIA化前の3DS実行ファイル
- `android/` と `ctr/` — APK/CIAのソース

CIAのインストールにはLuma3DS等の自作ソフト実行環境が必要です。自分が権利を持つタイトルのセーブだけを対象にしてください。
